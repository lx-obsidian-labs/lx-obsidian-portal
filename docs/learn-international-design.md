# Obsidian Learn international presentation system

The public learning school uses an editorial navy / white academic layout, consistent school subnavigation, programme facts, 4-stage learning map, 13 expandable books, accessible library search and stage filter, and an original free practice exercise. It preserves the shared company header, existing route paths, academic disclaimers, all 13 assignments, and protected material policy. The sample is independent of the protected PDFs and does not collect data. Search operates locally, no storage or remote requests. With JavaScript disabled, all book cards and details remain accessible and filtering controls are hidden. Book deep links expand native details. Mobile responsive rules target reflow and keyboard focus; no WCAG conformance claim without an independent audit. The course is not accredited, paid enrolment is not open, and protected textbook binaries, videos and LMS functions are not part of this layout release. Sources for design principles: W3C WCAG 2.2 (https://www.w3.org/TR/WCAG22/), reflow and focus visibility.
