# Vista Cinema for Smart TV

This is the same signed release APK as the phone build (one APK registers both a phone and a TV
launcher), packaged in `tv/` for TV download links.

## Features
- **Remote Optimized**: Full D-pad navigation support with row snapping and focus following.
- **Cinematic UI**: Large-screen layout with featured carousels.
- **High Performance**: Built with Compose for TV.

## Installation
1. Enable "Unknown Sources" in your TV settings.
2. Transfer the APK to your TV (using a USB drive or 'Send Files to TV' app).
3. Install `VistaCinema-TV-v1.0.6.apk`.
