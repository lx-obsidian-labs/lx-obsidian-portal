HELP & FILE SAFETY

Download questions, answered.

Which Vista Cinema file should I download?

Version 1.0.10 / code 17 is the current release. The phone and TV links intentionally contain the same signed APK, with launchers for each device type. Installation procedures and available interfaces differ. Older builds remain in the compatibility archive.

How can I verify the APK I downloaded?

The current phone and TV downloads have the SHA-256 fingerprint shown above. Calculate the downloaded file's SHA-256 digest and compare it character-for-character. On Windows PowerShell, use Get-FileHash -Algorithm SHA256 -Path "your-file.apk". A different result means you should not install that file. This shared checksum applies to 1.0.10; verify archived versions against their own release records.

Can Vista save every movie for offline viewing?

No. Downloads require an eligible direct media source; some embeds support streaming only. Transfers wait for an unmetered, non-roaming connection. Completed copies appear in Library → Downloads and play locally. Clear temporary cache preserves downloads; Delete in Downloads removes the selected copy.

Will upgrading reset onboarding or my saved titles?

An in-place update with the same signing certificate preserves local app data and onboarding completion. New viewers receive the introduction after guest/sign-in/profile setup; existing viewers can replay it in Settings → About. Uninstalling or clearing app data can remove local information.

Why does Synapse lead to GitHub instead of a direct ZIP?

The currently advertised Synapse build is published through the project's GitHub releases or Actions workflow. GitHub can require you to sign in for workflow artifacts, and older temporary artifacts may expire. We avoid showing a direct ZIP link without a verified permanent file.

Do the PDFs and template require an account?

No. The downloadable company overview, discovery workbook and CSV template are publicly accessible. You can save them and complete them at your own pace; the downloads do not submit your information to LX Obsidian Labs.

Is there a Windows or macOS installer for LX PDF Studio?

There is no verified desktop installer listed for LX PDF Studio. It runs in your browser at LX PDF Studio. If you need a custom document processing system for your business, discuss the requirements with our team.
