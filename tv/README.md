# Vista Cinema for Smart TV

This version is optimized for Android TV and Google TV devices.

## Features
- **Remote Optimized**: Full D-pad navigation support.
- **Cinematic UI**: Large-screen layout with featured carousels.
- **High Performance**: Built with Compose for TV.

## Installation
1. Enable "Unknown Sources" in your TV settings.
2. Transfer the APK to your TV (using a USB drive or 'Send Files to TV' app).
3. Install `VistaCinema-TV-v1.0.0.apk`.
