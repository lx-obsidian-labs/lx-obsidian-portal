Version 1.0.11 · Build 18 · iOS 17+ · Actual arm64 iPhoneOS device build

Device build available. Installation needs signing.

This is the native iPhone/iPad application compiled for real devices—not the simulator app. The downloadable IPA is currently unsigned. It cannot be installed on an ordinary iPhone by tapping a download as you can with an Android APK.

Apple Developer signing and a matching provisioning profile, or TestFlight distribution, are required before installation. A signed public iPhone installation link is not available yet.

Developer downloads · Not App Store/TestFlight installation · Release notes and checksums

A native start, with the Vista feel.

  • Featured movies, catalog rows, title search and clear recovery states.
  • Movie/series details, seasons, episodes and provider selection.
  • A local watchlist, adaptive layouts and the Vista dark/red visual identity.
  • Movie-only backup playback source and targeted provider-ad filtering.

The iOS preview is not yet feature-identical to Android. Account-backed polls, Firebase sign-in, AI/voice, offline downloads, notifications and watch history/resume are not included in this first iOS build.

Build verification

The macOS build passed its five automated iOS tests and generated the actual iPhoneOS arm64 archive. Physical iPhone playback and signing/distribution have not been verified.
