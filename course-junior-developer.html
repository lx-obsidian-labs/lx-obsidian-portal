Obsidian Learn / Software Development 001

The Junior Developer’s First Project

From your first line of code to your first live website. Build a Study Tracker using HTML, CSS and JavaScript, and learn the real development workflow.

Your learning outcomes

Become a project-ready beginner.

What you will learn

  • Plan software around a real problem and requirements.
  • Build an accessible, responsive interface.
  • Write JavaScript to manage application state and user events.
  • Save tasks, validate input and handle errors.
  • Debug, test and publish a website using Git and GitHub.

Who this is for

First-time programmers, self-taught developers, students and junior developers who have never deployed a project.

You'll need a computer, a modern browser, a text editor and internet access for setup and deployment. No prior coding experience or paid development software is required.

Course syllabus

Nine learning modules

The illustrated textbook contains 40 progressive lessons. Expand each module for the topics covered.

01 / Developer mindset and project planning

Define a problem, interview users, write requirements, sketch a wireframe and plan a minimum viable product.

02 / Development tools and the web

Set up the editor, terminal and browser; learn files, paths, HTTP and local development.

03 / HTML and accessibility

Build semantic markup, labelled forms, document structure and keyboard-friendly controls.

04 / CSS and responsive layout

Explore selectors, the box model, Flexbox, responsive design, contrast and focus.

05 / JavaScript and application behaviour

Understand variables, arrays, functions, events, the DOM, state and safe rendering. Implement add, complete and delete.

06 / Storage, validation and security

Persist tasks locally, handle invalid input, understand storage limitations and avoid unsafe rendering.

07 / Testing and debugging

Use developer tools, manual test cases, accessibility checks, debugging methods and refactoring.

08 / Git, GitHub and deployment

Track changes, document your work, publish a static website and present the project in a portfolio.

09 / Final practical assessment

Demonstrate the finished project, complete a 100-mark assessment and review your next steps.

Capstone project

Build your own Study Tracker.

A local-first web application that lets learners add, complete, reopen and delete study tasks, view progress and keep tasks across refreshes on the same browser.
