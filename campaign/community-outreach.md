# LX Insider — community outreach plan

Channel priority for this intake: **FCM to existing LX app users** (see `docs/LX_INSIDER_CAMPAIGN.md` §3) → WhatsApp → Facebook → LinkedIn → TikTok → campuses/entrepreneurship groups → Reddit/Android developer communities. Every channel drives to `https://www.lxobsidianportal.co.za/insider`. Copy is in `campaign/social/posts.md`; artwork in `campaign/artwork/`.

## Non-negotiable outreach rules

- Read each community’s promotion rules immediately before posting; ask admins where permission is required. No community is exempt.
- One post per community per intake; at most one reminder after 7+ days, only if the group allows it.
- Never scrape private contact details, never send unsolicited DMs, never import people into WhatsApp groups.
- Disclose the developer/company relationship in every developer-community post.
- No monetary amounts, guaranteed prizes, employment claims or review/rating incentives.
- Log each post with date, group, copy variant and permission status; stop immediately on a moderator request.

## Handoff checklist per community

- [ ] Rules read on the day of posting; permission granted where required.
- [ ] Copy adapted to the community (no cross-posting identical text).
- [ ] Link checked: `/insider` returns HTTP 200 (sender preflight also enforces this).
- [ ] Post logged with date and variant; reminder scheduled only if allowed.
- [ ] Applications attributed via the form’s source-channel field.
