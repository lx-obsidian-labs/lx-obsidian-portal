School methodology

Every lesson has a purpose.

Explain

Start with conceptual illustrations, vocabulary and worked examples.

Practise

Follow guided labs, then solve a similar task independently.

Demonstrate

Submit practical work, tests, reflection and a short explanation.

Improve

Use rubric-based feedback, targeted revision and resubmission.

Academic standards

Quality built into the school.

Formal assessment and moderation

Outcomes-mapped assignments, standardised rubrics, assessment records, independent moderation and learner appeals. Designed for accreditation readiness, not represented as accredited.

Academic quality framework

Obsidian Academic AI

Planned submission monitoring: text and code similarity, test evidence, AI-assisted review and human academic decisions.

Academic integrity framework

Lecturer teaching resources

13 planned PowerPoint packs, speaker notes, instructional videos, practical demonstrations, memoranda and accessible resources.

Protected student records

Planned secure uploads, private gradebook, role-based access, moderation records and transparent learner feedback.

School roadmap

Phase 1 · Curriculum and content

Develop 13 textbooks, assignment banks, marking guides, instructor videos and accessible course materials.

Phase 2 · Learning platform

Student accounts, private resources, enrolment payments, progress, assessment submission and support.

Phase 3 · Pilot and quality assurance

Review content, run learner pilots, validate rubrics, test accessibility, collect feedback and correct issues before launch.

Phase 4 · Growth

Develop specialised tracks in web engineering, Python automation and applied AI after the flagship programme is established.
