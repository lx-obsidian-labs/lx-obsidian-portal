WHATS NEW

Update Notices

Meet the smarter Vista in v1.0.9. Existing users: open Vista, tap Install Update Now, then approve Android's installer.

  • HEADLINE: Real NVIDIA-powered AI conversations — follow-up memory, your profile name and taste preferences, and knowledge of Vista's actual features. Sign in to use cloud AI.
  • NEW: Floating chat from the Home button without changing tabs, plus actions to open app pages and populated Search results.
  • NEW: Hands-free voice turns — tap the microphone once, hear the reply and continue. Say “stop listening” to end.
  • IMPROVED: AI and voice settings, highest-quality available Android voice selection, profile shortcuts and playback recovery.
  • REQUIRED: Version 1.0.9 replaces older versions using the same release signing certificate. Tap Install Update Now in the app.
  • PLANNED: A dedicated kids version is in planning. No release date has been announced.
